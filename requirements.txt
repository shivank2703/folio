# speculative. Versions are pinned exactly rather than floored: the committed
# index was built by these wheels, and an index embedded by one version of the
# model runtime and searched by another fails silently — plausible scores,
# wrong neighbours — instead of raising.
#
# Python 3.13 (3.13.1 here). Streamlit Community Cloud's deploy dialog defaults
# to 3.12, so pick 3.13 in Advanced settings: that is what every wheel below
# was resolved against and what the measurements in the README were taken on.
